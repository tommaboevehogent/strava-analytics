# Strava Analytics API

A personal Laravel REST API on top of my own Strava training data — OAuth2, webhook-driven background sync, Sanctum-authenticated endpoints, and an AI training-insight endpoint powered by Claude. Deployed on Laravel Cloud.

Started this project to learn more about PHP/Laravel.
